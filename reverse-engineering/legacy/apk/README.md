# Original Hazel app

Retail Razer companion APK for the Zephyr (`com.razer.hazel`, v1.0.1.184).

Place the binary here:

```
apk/com.razer.hazel.apk
```

The APK is **not committed** (large binary). Decompiled sources from `jadx` / `apktool` go in `apk/decompiled/` — also gitignored.

For UI exploration without hardware, see [research/hazel-app-ui.md](../research/hazel-app-ui.md) and [tools/scripts/run-hazel-mock-emulator.sh](../tools/scripts/run-hazel-mock-emulator.sh).
